# NEUREQ Phase 2b: Neural Inference and Evaluation Export

## Overview
`neureq_ph2b.py` serves as the final predictive layer of the core NEUREQ pipeline. It loads the optimal model weights trained in Phase 2a, dynamically encodes the sanitized textual and categorical data generated in Phase 1b, and calculates the final clinical relevance score (logit) for each patient-trial pair. 

[cite_start]Crucially for academic evaluation, this script handles sorting and formatting the predictions into formal `.txt` files compatible with the `trec_eval` toolkit[cite: 34], allowing for direct calculation of MAP, Precision, Recall, and nDCG metrics.

## Technical Architecture
* **Execution Mode:** Pure Inference (`model.eval()`, `torch.no_grad()`). Dropout layers are deactivated, and gradients are not stored, minimizing memory footprint.
* **Architecture Mirroring:** The script redeclares the `EligibilityBiLSTM` and `AdditiveAttention` classes. *Note: In PyTorch, the class definitions during inference must identically match the architecture used during training to successfully load the state dictionary.*
* **Fault Tolerance:** Incorporates a robust fail-safe. If the LLM failed to produce a valid 10-question evaluation (passed down as `None` from Phase 1b), the script automatically assigns a score of `-1e6`. This effectively pushes problematic, un-parsable data to the bottom of the ranked list rather than crashing the evaluation pipeline.

## File Dependencies

### Inputs
1. **Model Checkpoint:** `models_new/BiLSTM_ADD_ATTN_1196/model_epoch_12.pt` (The designated best weights from Phase 2a).
2. **Sanitized LLM Responses:** The output files generated by `neureq_ph1b.py`. The script is configured to run batch inference across four primary datasets to test generalization across different years and first-stage retrieval methods:
    * `2021 WholeQ`
    * `2021 WholeQ + RM3`
    * `2022 WholeQ`
    * `2022 WholeQ + RM3`

### Outputs
1. **TREC Run Files (`.reranked.txt`)**: Text files saved to `models_new/BiLSTM_ADD_ATTN_1196/epoch12/`. 

## Core Logic & Data Flow

1. **Model Instantiation:** Both the frozen `Bio_ClinicalBERT` and the custom BiLSTM are loaded and set to evaluation mode.
2. **Dataset Iteration:** The script loops through the four hardcoded test files.
3. **Data Encoding (`score_trial`)**:
    * Reads the sanitized dictionary.
    * Encodes "YES"/"NO"/"NA" into tensor arrays.
    * Passes the natural language justifications through `Bio_ClinicalBERT` to extract the 768-dimensional `[CLS]` embeddings.
4. **Prediction:** The BiLSTM predicts a single relevance logit for the sequence.
5. **Ranking and Formatting (`rerank_file`)**:
    * All scored trials for a single patient query (`qid`) are grouped.
    * The list is sorted in descending order based on the model's assigned score.
    * The sorted list is exported using the required space-delimited format: `query_id Q0 document_id rank score run_name`.

## Usage
Ensure the paths in the `CONFIGURATION` block match your local file structure and that you have selected your desired epoch checkpoint.

```bash
python neureq_ph2b.py
