# MFT-MonoT5 Baseline (Step 4/4): Max-Pooling Aggregation (`mft5_4.py`)

## Overview
This script executes the final aggregation phase of the **MFT-MonoT5** baseline evaluated in Section 4.2 of the NEUREQ paper.

In Step 3, the MonoT5 model circumvented transformer token limits by evaluating short, overlapping sentence segments rather than whole clinical trials. This produced a massive cache of segment-level relevance scores. This script applies a **Max-Pooling (MaxP)** algorithm to aggregate those localized segment scores back into a single, global relevance score for the entire clinical trial, allowing us to export the final ranked list.

## Technical Architecture & Mathematical Context

**The MaxP (Maximum Probability) Heuristic:**
Clinical trials are long documents filled with administrative boilerplate. If we averaged the relevance scores of all segments (Mean-Pooling), a single highly relevant inclusion criteria segment would be mathematically "drowned out" by dozens of low-scoring background segments. 

Max-Pooling solves this by assuming that **a document is only as relevant as its single most relevant passage**.
For a given patient query $q$ and a trial document $d$ consisting of segments $S = \{s_1, s_2, ..., s_n\}$, the final document score is:

$Score(q, d) = \max_{s_i \in S} P(Relevant | q, s_i)$

## File Dependencies

### Inputs
* **Segment Scores Cache:** `data/2022/sigir/segment_scores_WholeQ_RM3_T2022.jsonl`
  * *Format Expected:* JSONL outputs generated by `baseline_mft5_3.py`.
  * *Required Keys:* `"topic_id"`, `"trial_id"`, `"score"`.

### Outputs
* **Final TREC Run File:** `data/2022/sigir/monot5_rerank_WholeQ_RM3_T2022.txt`
  * *Format:* `topic_id Q0 trial_id rank score run_id`
  * This file is strictly capped at 100 trials per query and is immediately ready to be ingested by `trec_eval` to calculate MAP, nDCG@10, and Recall@10, or passed to `ttest.py` to calculate statistical significance against NEUREQ.

## Usage & Configuration

Ensure the `segment_scores_file` and `output_run_file` variables point to the specific dataset year and retrieval variant you are currently evaluating.

python mft5_4.py
