# SCT-BERT Baseline (Step 2/4): Negative Pair Generation (`sctbert_2.py`)

## Overview
This script finalizes the self-supervised dataset required to train the **SCT-BERT (Self-Supervised MonoBERT)** baseline. 

A binary classification model needs both positive and negative examples to calculate gradients and update its weights. Step 1 successfully identified the true positive matches (a trial's summary mapped to its own criteria). This script completes the dataset by generating negative examples. It iterates through the positive pairs and uses random sampling to pair the summary with the criteria of a completely different trial.

## Technical Architecture & Mathematical Context
* **Sampling Ratio:** The script generates negative examples at a **1:2 ratio** (1 positive pair for every 2 negative pairs). This slight negative skew is standard in Information Retrieval tasks because, in real-world search scenarios, the vast majority of retrieved documents are non-relevant. Teaching the model to aggressively penalize mismatches reduces false positives during inference.
* **Collision Prevention:** The script includes a critical `while` loop during sampling to guarantee that the randomly selected "negative" ID never matches the origin ID. Without this, the script could accidentally label a perfect match as a `0`, causing catastrophic forgetting during neural training.
* **In-Memory Optimization:** To prevent severe I/O bottlenecks during the generation of millions of records, the script pre-loads all available criteria strings into a hashed dictionary in system RAM, allowing for instant `O(1)` sampling.

## File Dependencies

### Inputs
* **Positive Pairs File:** `data/clinicaltrials/positive_pairs.jsonl`
  * *Origin:* Generated by `sctbert_1.py`.

### Outputs
* **Final Training Dataset:** `data/clinicaltrials/train_pairs.jsonl`
  * *Format:* JSON Lines.
  * *Volume:* Contains exactly 3x the number of rows as the input file (due to the 1:2 expansion).
  * *Schema:*
    ```json
    {
      "trial_id_summary": "NCT000001",
      "trial_id_criteria": "NCT999999",
      "summary": "This study examines breast cancer...",
      "criteria": "Inclusion: Patients with severe osteoporosis...",
      "label": 0
    }
    ```
