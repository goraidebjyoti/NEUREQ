# Baseline Inference: BERT & CT-BERT Cross-Encoders (`infer_Bert_ctBert.py`)

## Overview
This script executes the testing/inference phase for the dense neural baselines evaluated in Section 4.2 of the NEUREQ paper. It applies the fine-tuned weights generated by `train_Bert_ctBert.py` to the official unseen test datasets (TREC Clinical Trials Track 2021 and 2022).

The script evaluates the candidate lists produced by traditional, first-stage retrieval algorithms (like BM25 or BM25+RM3 pseudo-relevance feedback). It passes the patient query and the clinical trial text jointly through the trained transformer to generate a continuous probability score (`0.0` to `1.0`), overriding the original lexical ranking.

## Methodological Integrity: Best Checkpoint Selection
Neural ranking models—especially when trained on specific domains with limited labeled samples—are highly prone to "overfitting", where they memorize the training data and lose the ability to generalize.

To ensure academic rigor and a fair baseline comparison against NEUREQ, **this script must not automatically use the weights from the final training epoch.** Instead, the user must review the training logs from `train_Bert_ctBert.py`, identify the epoch that achieved the lowest `Validation Loss`, and manually point the `TRAINED_MODEL_CHECKPOINT` variable to that specific `.pt` file.

## Technical Architecture

* **Tokenization & Truncation:** To adhere strictly to the 512-token limit inherent to standard BERT models, the input is manually constructed and aggressively truncated: `[CLS] (1 token) + Query (179 tokens) + [SEP] (1 token) + Document (330 tokens) + [SEP] (1 token) = 511 tokens (+ padding to 512)`.
* **Inference Efficiency:** Executed sequentially but constrained within a `torch.no_grad()` block to disable the autograd engine, saving significant VRAM and minimizing forward-pass latency.
* **Output Standardization:** Results are sorted and formatted identically to the NEUREQ pipeline to ensure compatibility with `trec_eval` and the automated statistical significance testing script (`ttest.py`).

## File Dependencies

### Inputs
1. **Trained Checkpoint:** `models0/CT_MLM_BERT/bert_regression_epoch4.pt` (The optimal weights).
2. **First-Stage Retrieval Runs:** The text files defining the top 100 candidate trials per query (e.g., `runs/[YEAR]/FIRST_STAGE/WholeQ_RM3_RETRIEVAL_T[YEAR].txt`).
3. **Corpus & Queries:** `data/clinicaltrials/corpus.jsonl` and `data/[YEAR]/ct_[YEAR]_queries.tsv`.

### Outputs
* **Evaluated Run Files:** Standard `.txt` TREC format run files saved to `runs0/[YEAR]/[RUN_NAME]/`.

## Usage & Configuration

1. Set `YEAR` to either `2021` or `2022`.
2. Toggle `BASE_CHECKPOINT` and `RUN_NAME` depending on whether you are evaluating the generic `SIMPLE_BERT` or the domain-specific `CT_MLM_BERT`.
3. Set `TRAINED_MODEL_CHECKPOINT` to your best epoch.

```bash
python infer_Bert_ctBert.py
